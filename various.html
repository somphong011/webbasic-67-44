4.Download Links

 <a href="files/sample.txt" download>Download File</a>
Download Text File

ต้องมีไฟล์ในโฟเดอร์ถึงจะดาวโหลดได้จริง

    5.Button Links

    ลิ้งก์ที่ออกแบบให้คล้ายปุ่ม เหมาะกับปุ่มสมัคร ปุ่มอ่านเพิ่มเติม หรือปุ่มนำทาง

           <a href="https://www.example.com" class="btn-link">
       Visit Website
       </a>
    Visit Website

    สร้างปุ่มด้วยแท็ก button

        <button onclick="document.location='index.html'">HTML Tutorial</button>
    - มักใช้เมื่อลิงก์ไป หน้าในเว็บเดียวกัน
    - ผูกกับ DOM (document) โดยตรง


    <button onclick="location.href=document.location='index.html'">Visit Website</button>
    - นิยมใช้มากกว่า
    - เหมาะทั้งลิงก์ ภายในและภายนอกเว็บ
    - ผูกกับ window โดยตรง

    ปุ่มdocument.location

    ปุ่ม location.href

    ปุ่ม ตัวอย่างปุ่มจาก https://cssmippets.shefali.dev

    ปุ่ม เพิ่มขอบทอง

    ปุ่ม เพิ่มอนิเมชั่นเมื่อชี้ปุ่ม

    ปุ่ม ปุ่มสีดำ ชอบทอง แสงวิ่ง
